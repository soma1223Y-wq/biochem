代謝の概要

1代謝とは：同化・異化・両性経路

異化
大きな分子を分解してATPを取り出す反応。例：グルコースの酸化、脂肪酸のβ酸化。
同化
小さな前駆体から大きな化合物を合成する反応。例：アミノ酸からのタンパク質合成、グリコーゲン合成、脂肪酸合成。
両性経路
同化と異化の両方に関わる経路。例はクエン酸回路（オキサロ酢酸は糖新生やアスパラギン酸の材料＝同化、アセチルCoAの酸化でATP産生＝異化）。

健康な人では1日のタンパク質の同化量と異化量は釣り合っている。栄養失調やカロリー過多、悪液質などではこのバランスが崩れる。

栄養素消化・吸収後異化で最終的に
糖質単糖（主にグルコース）アセチルCoA
タンパク質アミノ酸アセチルCoA（一部はクエン酸回路の中間体）
脂肪脂肪酸＋グリセロールアセチルCoA

アセチルCoAの行き先

  • エネルギーが必要なとき：クエン酸回路でCO₂に酸化される。
  • エネルギーが十分なとき：脂肪酸合成（グリセロールとエステル化してトリアシルグリセロールに）、コレステロール・ステロイド合成、肝臓でのケトン体合成。
ひっかけ

ヒトでは、アセチルCoAからグルコースへの正味の変換はできない（クエン酸回路で2個の炭素がCO₂として失われる）。糖新生の材料は乳酸・糖原性アミノ酸・グリセロールなど。

例題 1-1

異化に分類される反応の組合せはどれか。
a アミノ酸からのタンパク質合成　b グルコースの酸化　c グリコーゲン合成　d 脂肪酸のβ酸化　e 脂肪酸合成
A a,c　B b,d　C c,e　D a,e　E b,e

答えを見る

B。bとdが異化。a・c・eは同化。

2タンパク質代謝と脂質代謝の概要

タンパク質代謝

  • 必須アミノ酸は食物から摂取。非必須アミノ酸は食物に加え、アミノ基転移反応による合成でも得られる。
  • 脱アミノ反応により、肝臓で尿素に変換される（アミノ基の行き先）。
  • アミノ基を失った炭素骨格は、クエン酸回路を経たCO₂への酸化、グルコース合成、脂肪酸合成、ケトン体合成に利用される。

脂質代謝

  • 脂肪酸の入手経路は、①食事、②糖質・アミノ酸からのアセチルCoAを材料とする脂肪酸合成。
  • 脂肪酸は、グリセロールとエステル化してトリアシルグリセロール（TG）になる。TGは分解された脂肪酸がβ酸化を受けてアセチルCoAになる。
  • アセチルCoAの行き先：①クエン酸回路でCO₂に、②コレステロール・ステロイドの合成、③肝臓でのケトン体合成。

※ 脂質代謝の概要は講義では範囲外の可能性が高いとされている部分。詳細は脂質の分野で扱う。

ひっかけ

「炭素骨格が尿素に変換される」は×。尿素になるのはアミノ基由来のアンモニア。炭素骨格はグルコース・脂肪酸・ケトン体・CO₂の材料になる。

例題 2-1

アミノ酸代謝について正しいのはどれか。
A 炭素骨格は尿素に変換される　B 非必須アミノ酸は食物からのみ得られる　C アミノ基は肝臓で尿素に変換される　D 炭素骨格はケトン体合成に使われない　E 必須アミノ酸はアミノ基転移で合成される

答えを見る

C。非必須アミノ酸はアミノ基転移でも合成される。

3糖質代謝の概要：基本式と4つの方向

C₆H₁₂O₆ ＋ 6O₂ ⇄ 6CO₂ ＋ 6H₂O　（ΔH＝−2938 kJ/mol、発熱）

グルコースは次の4つの方向に進む。

方向内容
① グリコーゲンへの変化筋肉・肝臓に貯蔵
② ペントースリン酸経路グルコース6-P・トリオースリン酸 → リボース5-P → DNA・RNA（核酸合成）
③ 解糖嫌気的 → 乳酸、好気的 → クエン酸回路へ
④ 脂肪酸合成過剰なアセチルCoAから

肝臓の役割

  • 腸で吸収した水溶性代謝物を血中から取り除き、基質の血中濃度を調整する。
  • 食間・絶食時にはグリコーゲン分解・糖新生によりグルコースを供給する（特に脳のため）。
例題 3-1

グルコースが核酸合成のリボースの供給源となる経路はどれか。
A 解糖　B ペントースリン酸経路　C グリコーゲン合成　D 脂肪酸合成　E 糖新生

答えを見る

B。

5インスリンと糖尿病

糖尿病は「インスリン作用不足による慢性高血糖」と定義される。

  • インスリンはGLUT4を細胞膜に発現させ、特に骨格筋などでグルコース取り込みを促進する。
  • インスリン作用不足では、筋肉の取り込みが低下、肝臓の糖新生が増加して、血糖値が上昇する。

ポリオール経路と合併症

赤血球・網膜・末梢神経・腎糸球体・水晶体などは、インスリン非依存的にグルコースを取り込む。高血糖で大量のグルコースが流入し、解糖が飽和すると、グルコース→ソルビトール→フルクトースのポリオール経路が活性化し、細胞内浸透圧が上昇して細胞障害を起こす（網膜症・神経障害・腎症・白内障）。

臨床

48歳男性、口渇・多尿、空腹時血糖高値。インスリン作用不足 → 筋肉のグルコース取り込み低下、肝臓の糖新生増加、血糖上昇。

例題 5-1

2型糖尿病でインスリン作用が不足したとき、グルコース取り込みが低下しにくい組織はどれか。
A 骨格筋　B 心筋　C 脂肪組織　D 脳・赤血球　E 骨格筋と心筋

答えを見る

D。脳・赤血球はGLUT3・GLUT1を介してインスリン非依存的に取り込む。

6細胞内での代謝経路の局在

場所代謝経路
細胞質（サイトゾル）解糖、ペントースリン酸経路、脂肪酸合成
ミトコンドリアクエン酸回路、脂肪酸のβ酸化、ケトン体合成、呼吸鎖（酸化的リン酸化）

ピルビン酸とオキサロ酢酸は、細胞質とミトコンドリアの間を移動する。ピルビン酸やオキサロ酢酸は細胞質とミトコンドリアの間を移動する（糖新生では、ミトコンドリアのオキサロ酢酸がホスホエノールピルビン酸を経てグルコース合成に向かう）。ミトコンドリアが機能不全に陥るとミトコンドリア病（ミトコンドリア脳筋症、乳酸アシドーシスなど）を起こす。

臨床：ミトコンドリア脳筋症

酸化的リン酸化が障害されるとATP産生を嫌気的解糖に頼り、NADHを再酸化できないためピルビン酸が乳酸へ変換され、血中乳酸が高値になる（運動後の脱力・頭痛など）。

例題 6-1

ミトコンドリアで起こる経路の組合せはどれか。
a クエン酸回路　b 解糖　c β酸化　d ケトン体合成　e 脂肪酸合成
A a,c,d　B a,b,c　C b,c,e　D b,d,e　E a,c,e

答えを見る

A。解糖と脂肪酸合成は細胞質。

7呼吸商（RQ）と呼吸交換比

呼吸商 ＝ 生成したCO₂ ／ 消費したO₂

  • 呼吸商は細胞レベルの値、呼吸交換比は呼気から求めた呼吸商。
  • 糖質のみの酸化で1.0、脂質は約0.7、タンパク質は約0.8。
  • 標準的な食事の24時間後は約0.85、糖質に富む食事の後は1に近く、空腹時は脂肪の酸化が増えて0.7に近づく。

計算：非タンパク質呼吸商（NP-RQ）

糖質と脂質だけを利用していると考える。糖質による酸素消費の割合をxとして、x×1＋(1−x)×0.7＝0.85 → x＝0.5。よって糖質50％・脂質50％。

覚える

グルコース1分子：6CO₂／6O₂＝1.0。「糖質は1、脂質は約0.7」を軸に、食後は上がり、空腹時は下がる。

例題 7-1

呼吸商が0.85のとき、糖質1・脂質0.7とすると、脂質の寄与（酸素消費比）はいくつか。
A 15％　B 30％　C 50％　D 70％　E 85％

答えを見る

C。x＋0.7(1−x)＝0.85 → x＝0.5。

悪液質は、がん・心不全・COPD・慢性腎不全・感染症などに伴う全身性の代謝異常症候群で、単なる低栄養ではない。

代謝省エネモード亢進

栄養補給改善する改善しにくい
炎症なしあり（IL-6など炎症性サイトカイン）
エネルギー源脂肪が中心筋肉のタンパク質も

悪液質での変化は、基礎疾患による炎症 → タンパク質異化速度の顕著な増加 → アミノ酸レベルの上昇 → 糖新生やエネルギー源として利用、の順。

例題 8-1

悪液質について正しいのはどれか。
A 栄養補給で容易に改善する　B 炎症を伴わない　C 筋肉も分解される　D 代謝は低下する　E 飢餓と同じ病態

答えを見る

C。炎症性サイトカインにより代謝が亢進し、筋肉も分解される。

解糖系とクエン酸回路

1解糖の概要：酸素の有無で行き先が変わる

グルコースを解糖するとピルビン酸ができる。

条件ピルビン酸の行き先
嫌気的条件（O₂が少ない）①ピルビン酸 → 乳酸、②NADH → NAD⁺（NAD⁺が再生され解糖が続く）
好気的条件（O₂がある）ピルビン酸 → アセチルCoA（クエン酸回路で使用される）
  • 骨格筋は嫌気的条件下で蓄積したグリコーゲンを消費し、ピルビン酸から乳酸が産生される。NADHの再酸化によりNAD⁺が再利用される。
  • 赤血球はミトコンドリアをもたないため、好気的でも乳酸は産生される（ミトコンドリアで酸化できない）。

解糖とピルビン酸酸化（ハーパー17章）

解糖ピルビン酸酸化
場所細胞質ミトコンドリアのマトリックス
酸素好気・嫌気どちらでも進む好気的条件でのみ進む（クエン酸回路・電子伝達系も同様）
反応グルコース（C6）→ピルビン酸（C3）×2ピルビン酸 → アセチルCoA＋CO₂＋NADH
正味2 ATP＋2 NADHNADH×2（グルコース1分子あたり）
  • 赤血球はミトコンドリアをもたない → ピルビン酸酸化が起こらない → エネルギー源は解糖で得られる2 ATPと2 NADHのみ。
  • 解糖・ピルビン酸酸化では NAD⁺→NADH が起こる。NADHは電子伝達系のATP産生に用いられる＝NADHは実質エネルギー源。
例題 1-1

赤血球で好気的条件でもピルビン酸酸化が起こらない理由はどれか。
A 酸素がない　B ミトコンドリアをもたない　C PDHが阻害される　D NAD⁺がない　E 解糖が行えない

答えを見る

B。

3不可逆反応・律速段階と、その逆反応の酵素

  • 解糖は細胞質で、好気的・嫌気的条件どちらでも進む（O₂に依存しない）。
  • 解糖の不可逆反応は3つ：(i) ヘキソキナーゼ（グルコース→G6P）、(ii) ホスホフルクトキナーゼ-1（F6P→F1,6BP）、(iii) ピルビン酸キナーゼ（PEP→ピルビン酸）。
  • 解糖の律速（反応速度を決める）はホスホフルクトキナーゼ-1（PFK-1）。ATPで阻害、G6Pでヘキソキナーゼが阻害される。
解糖（順方向）逆反応（糖新生）
①ヘキソキナーゼ／グルコキナーゼ（ATP→ADP）グルコース-6-ホスファターゼ（加水分解でH₃PO₄遊離）
③ホスホフルクトキナーゼ-1（ATP→ADP）フルクトース-1,6-ビスホスファターゼ
⑩ピルビン酸キナーゼ（ADP→ATP）逆反応の酵素はない → ピルビン酸カルボキシラーゼ＋PEPカルボキシキナーゼで迂回
  • リン酸基が付加／加水分解されるとき、ATP⇄ADP、あるいはH₃PO₄とともにリン酸基の加水分解が起こる。
  • ⑥のGAPDHではHの転移が起こるため NAD⁺⇄NADH。H₃PO₄によってリン酸基が付加／加水分解される。
  • ⑦のPGKはATP⇄ADP（ここだけ可逆）。

5ATP産生量（好気・嫌気）

NADH＝2.5 ATP、FADH₂＝1.5 ATPに相当（覚える！）。エネルギー産生は、どの過程で生じるかを考えず量だけで考えると誤る。

条件計算ATP
解糖（好気）2 NADH＋2 ATP＝2×2.5＋27
ピルビン酸酸化＋クエン酸回路8 NADH＋2 FADH₂＋2 ATP(GTP)＝8×2.5＋2×1.5＋225
合計7＋2532 ATP
解糖（嫌気）4−22

嫌気的条件では、NADH・FADH₂が電子伝達系で働かないため、ATPは産生できない（2 ATPのみ）。同量のATPを得るにはより多くのグルコースを代謝しなければならない。

6悪性リンパ腫・FDG-PET・ワールブルグ効果

FDG-PET

  • 悪性リンパ腫はグルコースを取り込み、解糖する。PET（陽電子放出断層撮影）画像を診断に用いる。
  • FDG：グルコースの2位が−OH→−¹⁸F（放射性に変化したもの）。FDGは解糖の過程でヘキソキナーゼによりリン酸化されるが、それ以降は代謝されず蓄積する → PETで写る。

好気的解糖（ワールブルグ効果）

通常は好気的条件下で、グルコース→解糖→ピルビン酸→クエン酸回路・酸化的リン酸化→多くのATP（32ATP）。しかしがん細胞では好気的でも、グルコース→解糖→ピルビン酸→嫌気的解糖→乳酸＋少しのATP（2ATP）。

がん細胞が好気的解糖をするメリット：

  • ① ATPをすばやく産生。
  • ② 解糖の中間生成物から脂質・アミノ酸・核酸を合成できる → 細胞の成長促進。
  • ③ 乳酸が増加 → 酸性化 → 免疫による排除が弱まる → がん細胞の浸潤・成長を促進。

赤血球の迂回経路（ラパポート・リューベリング経路）

  • 通常：1,3-BPG →（PGK、ATP産生）→ 3PG。
  • 赤血球特有：1,3-BPG →（ビスホスホグリセリン酸ムターゼ）→ 2,3-BPG →（2,3-BPGホスファターゼ）→ 3PG。
  • デメリット：本来の経路で発生するATP産生が無くなる。メリット：2,3-BPGはヘモグロビンと結合しO₂親和性を低下 → ヘモグロビンから組織へのO₂の運搬量が増加。
例題 6-1

ワールブルグ効果について正しいのはどれか。

7ピルビン酸デヒドロゲナーゼ（PDH）とビタミンB₁

解糖で得られるピルビン酸はPDHにより ピルビン酸＋CoA＋NAD⁺ → アセチルCoA（C2）＋CO₂＋NADH（不可逆）。補酵素A（CoA）にアセチル化したC₂＝アセチルCoA。

アセチルCoAはエネルギー産生（クエン酸回路）、エネルギー過剰時の脂肪酸合成に用いられる。

  • PDHの活性化にはビタミンB₁（チアミン）由来のチアミンピロリン酸（TPP）が必要。
ビタミンB₁欠乏

ビタミンB₁不足 → TPP不足 → PDH不活性 → ピルビン酸が増加 → 乳酸増加 → 乳酸アシドーシス（体内のpH低下）、ATP産生低下 → 病気：脚気、ウェルニッケ脳症、コルサコフ症候群。

8クエン酸回路の概要と医学的重要性

  • 糖質・脂質・タンパク質の酸化のための最終的な共通回路。
  • アセチルCoAのアセチル部分（C2）がオキサロ酢酸（C4）と反応してクエン酸（C6、トリカルボン酸）を生成してスタート。
  • 途中で2分子のCO₂が放出され、オキサロ酢酸が再生される（回路維持にはオキサロ酢酸の再生が重要）。
  • 酵素はミトコンドリアのマトリックスに局在する。
  • アセチルCoAの酸化の間に補酵素は還元され、共役して続く呼吸鎖でATPが産生される（酸化的リン酸化）。この過程は好気的で、酸化剤として酸素を必要とする。

医学的重要性

  • 高アンモニア血症：血中アンモニアが上昇 → 肝細胞での尿素回路でアンモニアを処理 → クエン酸回路の中間生成物（α-ケトグルタル酸など）を過剰に利用 → 回路が回らずATP合成低下。
  • クエン酸回路の酵素が欠損すると、特に中枢神経でATP合成が低下し、神経障害を起こす。
例題 8-1

クエン酸回路について正しいのはどれか。
A 酵素は細胞質に局在する　B アセチルCoAとオキサロ酢酸からクエン酸が生じる　C 回路1周で4分子のCO₂が放出される　D 嫌気的条件で進む　E 糖質のみの酸化経路である

答えを見る

B。1周で2分子のCO₂、好気的、3大栄養素に共通。

9呼吸の目的と補酵素の再生

呼吸の目的はATPを産生してエネルギーを取り出すこと。そのために電子（e⁻）を利用する。

  • 基質を酸化（e⁻を奪い取る）してe⁻を得る。
  • ここで使うのがNAD⁺・FAD（酸化型補酵素）。基質を酸化し、自身はNADH・FADH₂（還元型補酵素）となり、「e⁻の運び屋」になる。
  • 代謝を常に行うには酸化型補酵素を再生させる必要がある → O₂が酸化剤としてHを受け取り（→H₂O）、ここで放出されるe⁻のエネルギーとH⁺の濃度勾配を利用してATPを合成（酸化的リン酸化）。
換算ATP
NADH 1分子2.5 ATP
FADH₂ 1分子1.5 ATP
GTP 1分子1 ATP

グリコーゲン代謝と糖新生

1グリコーゲンの構造と合成

グリコーゲンは動物の貯蔵多糖（植物ではデンプンに相当）。α-D-グルコースが枝分かれした重合体で、ヒトでは肝臓と筋肉にほとんど貯蔵される。全グリコーゲンの約75％は筋肉に存在し、肝臓のグリコーゲンは空腹時に血糖値を維持するための貯蔵として働く。

  • グルコースのα1→4結合の鎖に、α1→6結合の枝分かれをもつ貯蔵多糖。肝臓（血糖維持）と骨格筋（自身のエネルギー）に貯蔵。
  • 合成の流れ：グルコース →（グルコキナーゼ、解糖と共通）→ G6P ⇄（ホスホグルコムターゼ、可逆）→ G1P →（UDP-グルコースピロホスホリラーゼ、UTP→PPi、不可逆）→ UDP-グルコース →（グリコーゲンシンターゼ、不可逆）→ グリコーゲン。
  • グリコーゲンシンターゼ：UDP-グルコースのC1と、グリコーゲン末端グルコース残基のC4の間にα1→4結合を形成し、UDPを遊離。
  • 分枝酵素：α1→4鎖が11残基以上に伸びると、鎖の一部（約7残基）を切断し、α1→6結合で別の鎖に転移する（グルコース同士の結合に関与）。
ひっかけ

グリコーゲン合成のグルコース供与体はUDP-グルコース（ATP-グルコースやGDP-グルコースではない）。

例題 1-1

答えを見る

B。α1→6は分枝酵素。

2グリコーゲンの分解

  • 分解には順序がある。①グリコーゲンホスホリラーゼ（律速、PLP）が最も外側の鎖の末端からグルコース残基を残り4分子になるまで順次分解しG1Pを生成。②グルカントランスフェラーゼ（脱分枝酵素の一部）が残り4分子のうち末端から3分子を別の枝へ転移し、α1→6結合をもつグルコース1個を露出。③1,6-グリコシダーゼがα1→6結合を加水分解して遊離グルコースを生じる。
  • G1P →（ホスホグルコムターゼ）→ G6P →（G6Pase）→ グルコース。G6Paseは肝臓・腎臓・膵臓のみに発現し、グルコースを血中へ放出できる。筋肉は発現していないため、筋グリコーゲンの分解は直接的には血中グルコースを生じない（解糖に利用される）。

3ホルモンによる調節

グルカゴン／アドレナリンインスリン
PKA活性化—
分解（ホスホリラーゼ）促進抑制
合成（シンターゼ）抑制促進（PP1で脱リン酸化）
  • グリコーゲンシンターゼ（合成）は脱リン酸化で活性、リン酸化で不活性。グリコーゲンホスホリラーゼ（分解）はリン酸化で活性、脱リン酸化で不活性。
  • これらをリン酸化する酵素がPKA（cAMP依存性プロテインキナーゼ）、脱リン酸化する酵素がPP1（プロテインホスファターゼ1）。
  • ATP →（アデニル酸シクラーゼ）→ cAMP。アデニル酸シクラーゼはアドレナリン・ノルアドレナリン・グルカゴン・インスリンなどのホルモンに応答して活性が変わる。cAMPがPKAの活性を調節する。
  • インスリン（血糖値↓）：肝臓でグリコーゲン合成↑・分解↓。PP1活性化 → シンターゼ活性、ホスホリラーゼ不活性。
  • グルカゴン（血糖値↑）：肝臓で合成↓・分解↑。PKA活性化 → シンターゼ不活性、ホスホリラーゼ活性。
  • アドレナリン（血糖値↑）：PKA活性化＋Ca²⁺（筋肉のみ）。合成↓・分解↑。
  • グルカゴンは肝臓に作用（筋肉の受容体は乏しい）。

5糖新生

糖新生とは、糖質でない前駆体（例：乳酸・ピルビン酸）からグルコースを合成する過程。解糖には不可逆反応があるため、糖新生は解糖に用いる酵素だけでは逆反応は不可。解糖を迂回する経路でグルコースに戻す（とはいえ大体は解糖の中間体まで戻し、そこから解糖の逆を送る）。主に肝臓（一部は腎臓）で起こる。

解糖の不可逆反応糖新生の迂回酵素
グルコース→G6P（HK/GK）グルコース-6-ホスファターゼ（G6Pase）
F6P→F1,6BP（PFK-1）フルクトース-1,6-ビスホスファターゼ（FBPase-1）
PEP→ピルビン酸（PK）ピルビン酸カルボキシラーゼ（PC）＋PEPカルボキシキナーゼ（PEPCK）
  • 原料：乳酸、糖原性アミノ酸（アラニンなど）、グリセロール、プロピオン酸。脂肪酸（偶数）は不可。
  • PCはビオチン依存、アセチルCoAで活性化（脂肪酸酸化が進むと糖新生が促進）。
  • インスリン→抑制、グルカゴン・コルチゾール→促進。
  • 乳酸はピルビン酸に（後述のコリ回路）、糖原性アミノ酸（例：Asp）はクエン酸回路の中間体や解糖の中間体に変換可能なので、糖新生でグルコースに変換できる。
  • 糖新生が促進されすぎると高血糖（糖尿病、糖尿病ケトアシドーシス）、しなさすぎると低血糖（アルコール性低血糖、肝不全）。
  1. 運動中の（O₂が少ない）筋細胞では、嫌気的解糖でピルビン酸＋NADH → 乳酸＋NAD⁺（LDH）。赤血球などミトコンドリアをもたない細胞も同様。
  2. 乳酸が血流で肝臓へ → 肝臓は血流が豊富でO₂が多く、乳酸 → ピルビン酸（LDH）→ 糖新生でグルコース。
  3. グルコースを血流で、ミトコンドリアをもたない細胞や筋細胞に供給（①へ戻る）。この一連の流れがコリ回路。
臨床

アルコール：肝でNADH／NAD⁺比が上昇 → 乳酸→ピルビン酸、OAA→リンゴ酸が進まず糖新生が抑制 → 低血糖。糖尿病性ケトアシドーシス：インスリン欠乏で糖新生・脂肪分解↑、ケトン体産生↑。

例題 5-1

A PK＋PFK-1　B PC＋PEPCK　C G6Pase＋FBPase　D HK＋PK　E LDH＋PDH

答えを見る

B。

ペントースリン酸経路・ウロン酸回路・果糖代謝

1ペントースリン酸経路（PPP）

  • G6Pから始まり、ATPは産生しない。主な機能は2つ。
  • ① NADPHの産生：脂肪酸・コレステロール・ステロイド・NO合成、還元型グルタチオン維持（抗酸化）、好中球のNADPHオキシダーゼ（殺菌）。
  • ② リボース5-リン酸の生成（ヌクレオチド合成）。
  • 電子伝達系でATPをつくるのはNADH（NADPHではない）。
段階性質産物
酸化的（G6P→Ru5P）不可逆、G6PDが律速NADPH×2＋CO₂×1
非酸化的可逆（トランスケトラーゼ・トランスアルドラーゼ）スタートはG6P、ゴールはF6P＋E4P（講義）。リボース5-Pも生成。解糖の中間体に変換され、エネルギー産生や糖新生に利用

G6P 3分子が酸化的段階を通ると、NADPH 6分子、CO₂ 3分子。

答えを見る

B。

2NADPHと赤血球・G6PD欠損症

赤血球ではPPPがNADPHの唯一の供給源。

G6PD欠損 → NADPH↓ → GSH↓ → H₂O₂蓄積 → 膜の酸化障害 → 溶血性貧血

  • H₂O₂はグルタチオンペルオキシダーゼが還元型グルタチオン（GSH）を使って分解（2GSH＋H₂O₂→GSSG＋2H₂O）。
  • GSSGはグルタチオンレダクターゼがNADPHを使ってGSHに戻す。
  • 誘因：感染、抗マラリア薬などの薬剤、ソラマメなどの酸化ストレス。X連鎖潜性遺伝。
臨床

20歳男性、抗マラリア薬の内服後に黄疸・暗赤色尿・貧血 → G6PD欠損症による溶血。

例題 2-1

G6PD欠損症で溶血が起こる機序はどれか。
A ATP産生低下　B NADPH低下によりGSHを維持できず酸化障害　C ヘム合成低下　D 解糖系の停止　E グロビン鎖の異常

答えを見る

B。

3ウロン酸回路とグルクロン酸抱合

  • グルコース→G6P→G1P→UDP-グルコース（ここまでグリコーゲン合成と共通）→UDP-グルクロン酸。ATPは産生しない。
  • UDP-グルクロン酸の行き先：①グルクロン酸抱合（ビリルビン・薬物・ホルモン。水溶性が上がり尿・胆汁へ排泄）、②GAG合成（ヒアルロン酸・コンドロイチン硫酸・ヘパリン＝結合組織）、③アスコルビン酸合成。
  • ヒトは③の酵素をもたない → ビタミンCは食事から摂取。
  • 本態性ペントース尿症：ウロン酸経路の酵素欠損。
例題 3-1

ヒトで進まないウロン酸回路の経路はどれか。
A グルクロン酸抱合　B GAG合成　C ビタミンC合成　D UDP-グルコース合成　E ビリルビン抱合

答えを見る

C。

4フルクトース代謝

  • 供給源：果物、はちみつ、清涼飲料水など。ショ糖（グルコース＋フルクトース）が多い。
  • 代謝は主に肝臓。
  • PFK-1をバイパスするため、ATP・クエン酸・AMPなどによる調節を受けず、大量摂取でも解糖下流に流れ続ける（→脂肪酸合成へ）。
  • グルコースはG6Pから、フルクトースはF1P→DHAP・GAPから解糖に入る。
  • 遺伝性果糖不耐症：アルドラーゼB欠損（F1P蓄積、低血糖・肝障害）。本態性果糖尿症：フルクトキナーゼ欠損（無症状）。
ひっかけ

フルクトース代謝のキナーゼはフルクトキナーゼであって、ホスホフルクトキナーゼ-1ではない。

B。
