1タンパク質栄養失調

2必須アミノ酸と非必須アミノ酸

  • 必須9種：His, Ile, Leu, Lys, Met, Phe, Thr, Trp, Val。非必須11種。
  • 非必須アミノ酸は1〜3段階で合成でき、必須アミノ酸は10数段階が必要。
  • アルギニン：尿素回路で合成できるが、成長期は不足し得るため条件付き必須。
  • システイン：非必須だが、必須のメチオニンから合成されるため不足し得る。チロシンはフェニルアラニンから合成（Pheが不足するとTyrも不足）。
  • 必須アミノ酸が欠乏すると、深刻な代謝異常や成長障害が起こる。
ひっかけ

チロシンの材料はフェニルアラニン（トリプトファンではない）。ヒスチジンはヒトで合成経路をもたない。

C。

3非必須アミノ酸の合成

合成法の3パターン

グループ作り方材料・仕組み主なアミノ酸
A 基本路線エネルギー代謝の中間体（解糖系・TCA回路）を材料にするアミノ基転移など1〜3段階グルタミン酸、アスパラギン酸、セリン など
B 変換路線必須アミノ酸から作る食事から得た必須アミノ酸を別の非必須アミノ酸に変えるシステイン、チロシン
C 後付け修飾特殊な仕組みで作るタンパク質に組み込まれた後に特殊な部位を変換し、特殊な機能を付与ヒドロキシプロリン、セレノシステイン
  • グルタミン酸：2-オキソグルタル酸＋NH₄⁺＋NAD(P)H（GDH、ミトコンドリア）。アンモニウムイオン濃度を下げる重要な反応（シッフ塩基を経る2段階）。リソソームではない。
  • グルタミン：Glu＋NH₃＋ATP（グルタミン合成酵素）。
  • アスパラギン酸：OAA＋Glu（アスパラギン酸アミノトランスフェラーゼ、AST）。
  • アラニン：ピルビン酸＋Glu/Asp（ALT、補酵素PLP）。アミノ基転移反応で、ATP不要・可逆・無毒（アンモニウムイオンが発生しないため）。アミノ基供与体はグルタミン酸・アスパラギン酸。
  • アスパラギン：Asp＋Gln＋ATP → Asn＋Glu＋AMP＋PPi。
  • セリン：3-ホスホグリセリン酸 →（3-PGDH、酸化）→ 3-ホスホヒドロキシピルビン酸 →（アミノ基転移）→ 3-ホスホセリン →（ホスホセリンホスファターゼ、脱リン酸化）→ セリン。3-PGDHが律速で、セリンによるフィードバック阻害を受ける。
  • セリン⇄グリシン：SHMT、THFが関与し、N5,N10-メチレンTHFが生じる。THFは葉酸由来の1炭素単位の担体。
  • システイン：セリン＋ホモシステイン →（シスタチオニンβ-シンターゼ）→ シスタチオニン →（シスタチオニンγ-リアーゼ）→ システイン＋ホモセリン。硫黄の供給源はホモシステイン（メチオニン由来）。
  • チロシン：Phe→Tyr（フェニルアラニンヒドロキシラーゼ、BH₄必要、不可逆）。

5タンパク質の分解

  • 代謝回転：体内タンパク質の約1〜2％/日。半減期は様々（短い：オルニチンデカルボキシラーゼ、長い：クリスタリン・コラーゲン）。

アンモニア処理と尿素回路

1アミノ基転移とアンモニアの運搬

  • アミノ基の行き先はアンモニア → 尿素（炭素骨格ではない）。
  • アミノ基転移反応：アミノ酸＋2-オキソグルタル酸 ⇄ α-ケト酸＋グルタミン酸。補酵素はPLP（ビタミンB₆）。反応はピンポン機構、中間体はシッフ塩基。ALT・ASTがこの反応を触媒。
  • グルタミン酸は肝ミトコンドリアでGDHにより酸化的脱アミノされ、NH₄⁺を遊離（NAD⁺・NADP⁺どちらも使用可）。GDHはATP・GTPで活性低下、ADP・GDPで上昇。
  • 末梢ではグルタミン合成酵素がGlu＋NH₃＋ATP→Glnとして無毒化。グルタミナーゼがGlnからNH₄⁺を遊離（肝臓→尿素回路、腎臓→尿中排泄）。
  • 血中の無毒な運搬形：アラニン（筋→肝）とグルタミン（腸・腎へ）。
アラニングルタミン
由来筋肉筋肉・脳など
行き先主に肝臓（グルコース-アラニン回路：尿素回路・糖新生）腸・腎臓
臨床

代謝性アシドーシスでは腎のグルタミナーゼが上昇し、NH₄⁺を尿中に排泄してpHを調節する。

筋肉から肝臓へアンモニア（窒素）を運ぶアミノ酸はどれか。
A アラニン　B チロシン　C システイン　D プロリン　E トリプトファン

答えを見る

A。

2食後・空腹時のアミノ酸の動き

空腹時

  • 筋肉のタンパク質が分解され、分岐鎖アミノ酸（Val, Leu, Ile）がエネルギーとして使われる。
  • 生じた窒素はアラニン・グルタミンとして運ばれ、最終的に肝臓で尿素になる。
  • グルコース-アラニン回路：筋でアミノ基をピルビン酸に結合してアラニンとして血中へ → 肝臓でアラニンからアミノ基を外し、アミノ基は尿素回路へ、ピルビン酸は糖新生へ → 生じたグルコースを再び筋肉へ。

満腹時

  • 腸から吸収したアミノ酸は肝臓へ。分岐鎖アミノ酸は肝臓を素通りして筋肉に運ばれる。
  • 食後：吸収されたアミノ酸は門脈を通ってまず肝臓へ。
  • 分岐鎖アミノ酸（Val, Leu, Ile）は肝臓に代謝する酵素が乏しく、素通りして筋肉へ（吸収直後約20％→肝通過後約60％）。
  • 空腹時は筋肉が血中遊離アミノ酸の半分以上を供給する。筋肉のアミノ酸は脳や肝臓（糖新生）に運ばれる。
  • 窒素排泄形：アンモニア（硬骨魚類、エラから希釈）、尿酸（鳥類・爬虫類、固体で水分損失が少ない）、尿素（陸生哺乳類）。
例題 2-1

食後に肝臓を素通りして筋肉に運ばれるアミノ酸はどれか。
A 芳香族アミノ酸　B 分岐鎖アミノ酸　C 酸性アミノ酸　D 含硫アミノ酸　E 塩基性アミノ酸

答えを見る

3尿素回路

猛毒のアンモニアを、水溶性の無毒な尿素にして排泄する。肝細胞で、反応①②はミトコンドリア、③④⑤は細胞質。

番号酵素基質→産物
①CPS I（律速）NH₄⁺＋CO₂→カルバモイルリン酸
②OTC＋オルニチン→シトルリン
③アルギニノコハク酸シンターゼ＋Asp→アルギニノコハク酸
④アルギニノコハク酸リアーゼ→アルギニン＋フマル酸
⑤アルギナーゼ→尿素＋オルニチン
  • CPS IはN-アセチルグルタミン酸（NAG）で活性化（NAGS欠損でも高アンモニア血症）。
  • 尿素1分子でATP 3分子（④でAMPになるため高エネルギーリン酸結合は4）。
  • フマル酸はTCA回路へ。
  • CPS I（ミトコンドリア、尿素回路）とCPS II（細胞質、ピリミジン合成）を区別。

アミノ酸の炭素骨格と特殊生成物

1アミノ酸の炭素骨格の行き先

アミノ基を除いた炭素骨格は、7つの代謝中間体に集約される。

  • 糖原性アミノ酸：ピルビン酸、α-ケトグルタル酸、スクシニルCoA、フマル酸、オキサロ酢酸になる → クエン酸回路で酸化（ATP）あるいはグルコース合成。
  • ケト原性アミノ酸：アセチルCoA、アセトアセチルCoAになる → ケトン体や脂肪酸の合成（グルコースには変換できない）。
  • ロイシン・リシンは純粋なケト原性。
  • 例：アスパラギン →（アスパラギナーゼ）→ アスパラギン酸 →（アミノ基転移）→ オキサロ酢酸。
覚える

ノートの指示：「これを覚えましょう！」＝ 糖原性／ケト原性の振り分けと、7つの中間体への集約。

例題 1-1

純粋なケト原性アミノ酸の組合せはどれか。
A ロイシン・リシン　B アラニン・セリン　C アスパラギン・アスパラギン酸　D フェニルアラニン・チロシン　E バリン・イソロイシン

答えを見る

A。

2アミノ酸代謝の先天性代謝異常

疾患欠損酵素症状・ポイント
高アルギニン血症アルギナーゼ（尿素回路）尿素回路の一つとして重要。2〜4歳頃まで症状が目立たない
フェニルケトン尿症（PKU）フェニルアラニンヒドロキシラーゼ重度の精神遅滞。Phe過剰 → フェニルピルビン酸・フェニル乳酸・フェニル酢酸が増加。治療はフェニルアラニン制限食。Tyrが本来作れず必須となる
メープルシロップ尿症（MSUD）分枝α-ケト酸デヒドロゲナーゼ複合体尿がメープルシロップ臭、重度の神経障害。分岐鎖アミノ酸（Leu, Val, Ile）の共通の最初の3反応（アミノ基転移、脱炭酸、脱水素）。遺伝的多様性あり

先天性代謝異常を防ぐには

  • 早期発見が最善。方法として新生児マススクリーニング（タンデム質量分析法）。
  • 生後数日の新生児の血液（濾紙血）から、アミノ酸・アシルカルニチンを一度に測定できる。症状が出る前に診断し、食事療法などを始められる。
ひっかけ

PKUは「フェニルアラニン→チロシン」の酵素欠損。メープルシロップ尿症は「分岐鎖α-ケト酸」の脱水素酵素欠損。ホモシスチン尿症はシスタチオニンβ-シンターゼ。名称と酵素の組合せで出題される。

3ヘム生合成の流れと酵素

① ALAの合成（スタート）

  • 場所：ミトコンドリア。材料：スクシニルCoA（TCA回路の中間体）＋グリシン。
  • 酵素：ALAシンターゼ（ALAS）。2つの物質を縮合しδ-アミノレブリン酸（ALA）を作る。
  • このALASの反応が、ヘム合成全体の中で最も遅い律速段階。

② ポルホビリノーゲン（PBG）の生成

  • ミトコンドリアからサイトゾルへ移動して行われる。2分子のALAが結合し、2H₂Oが抜けて最初のピロール環をもつPBGが生成。
  • 酵素：ALAデヒドラターゼ（ポルホビリノーゲンシンターゼ）。構造維持に亜鉛（Zn）が必要 → 鉛中毒で阻害され、手前の物質のALAが蓄積（貧血・神経症状）。

③ ウロポルフィリノーゲンIIIの生成

  • まず4分子のPBGを一直線に繋げ、直鎖状テトラピロール「ヒドロキシメチルビラン」を作る。
  • 次に丸めて環状化。ウロポルフィリノーゲンIIIシンターゼが働くと、規則的な配列（I型）ではなく、第4ピロール環の配置が反転した非対称のIII型が生成。

④ 以降

  • サイトゾル：ウロポルフィリノーゲンIII →（ウロポルフィリノーゲンデカルボキシラーゼ）→ コプロポルフィリノーゲンIII。
  • ミトコンドリア：→（コプロポルフィリノーゲンオキシダーゼ）→ プロトポルフィリノーゲンIII →（プロトポルフィリノーゲンオキシダーゼ）→ プロトポルフィリンIII。
  • 最終ステップ：ミトコンドリア内でフェロケラターゼがプロトポルフィリンの中央にFe²⁺を挿入し、ヘムが完成。
  • 酸化による有色化：無色のポルフィリノーゲンが光などで酸化されると、二重結合（共役系）を持つポルフィリンになり、有色で強い蛍光性を持つ。
覚える

経路の順：ALA → PBG → ヒドロキシメチルビラン → ウロポルフィリノーゲンIII → コプロポルフィリノーゲンIII → プロトポルフィリノーゲン → プロトポルフィリン → ヘム。局在はミトコンドリア → サイトゾル → ミトコンドリア。

5ポルフィリンの性質：ソーレー帯と光線過敏症

  • 酸化されたポルフィリンは、二重結合が連なる共役系をもつため、特定の色を持ち、光を吸収する。
  • ソーレー帯：吸収スペクトルの400 nm付近にある非常に鋭く高いピーク。すべてのポルフィリンに共通。

6ヘム合成の異常：鉛中毒とポルフィリン症

ヘムを作るための8つの酵素のいずれかがうまく働かず、正常なヘム合成ができなくなる状態。環境要因による後天性と生まれつきの先天性がある。

後天性：鉛中毒

  • 鉛（Pb）が酵素（ALAデヒドラターゼやフェロケラターゼ）の働きに必須な構造（チオール基）に結合して阻害。
  • ヘムが作れず、血液中に手前の物質（ALAやプロトポルフィリンなど）が蓄積。

先天性：ポルフィリン症

  • 8つの酵素のうちALAS1を除く7つの遺伝子異常が「ポルフィリン症」を引き起こす（ALAS1の完全欠損は致死的、ALAS2の低下は貧血）。
  • 基本ルール：経路の途中で酵素が働かなくなると、その反応の「手前」の産物（中間体）が蓄積する。
  • 分類：骨髄性（主に赤血球を作る骨髄で異常。例：先天性赤芽球性ポルフィリン症）、肝性（主に肝臓。例：急性間欠性ポルフィリン症）。

7ヘムの分解とビリルビン代謝

① 開環

  • 約120日の寿命を終えた赤血球は、脾臓や肝臓のマクロファージで分解され、ヘムが取り出される。
  • ヘムオキシゲナーゼがリングの一部（α-メチン橋）を切り開き直線状にする。このとき鉄（Fe）と一酸化炭素（CO）が放出される。
  • 色：ヘム（赤紫）→ ビリベルジン（緑）→ 還元酵素によりビリルビン（黄）。打撲の「青アザ」が治る過程の色の変化はこの代謝反応そのもの。

② 血中輸送と間接ビリルビン

  • できたてのビリルビンは非極性（疎水性）で水に溶けず、血中を単独で移動できない。
  • 血清アルブミンと結合して肝臓へ運ばれる。肝で未処理のものを、臨床では間接ビリルビン（非抱合型）と呼ぶ。

③ 肝での処理と直接ビリルビン

  • 肝細胞内でUDP-グルクロノシルトランスフェラーゼにより水に溶けやすいグルクロン酸を2つ結合（グルクロン酸抱合）。
  • 水溶性（極性の高い）のビリルビンジグルクロニドを、臨床では直接ビリルビン（抱合型）と呼ぶ。胆汁に溶け込み腸管へ排泄される。

④ 腸管での排泄サイクル

  • 胆汁として腸管に排出された直接ビリルビン（黄色）は、腸内細菌に還元されて無色のウロビリノーゲンになる。
  • 大部分は酸化されて茶褐色のステルコビリンとなり、便として排泄（便が茶色いのはヘムの分解産物）。
  • ウロビリノーゲンの一部は腸から再吸収され、門脈を通って肝臓へ戻る（腸肝循環）。
例題 7-1

8黄疸と臨床検査

  • 高ビリルビン血症：血中ビリルビンが約1 mg/dLを超えた状態。肝臓の処理能力を超えて作られすぎる、あるいは肝臓や胆道の障害でうまく排泄できないために起こる。
  • 黄疸：血中濃度が2〜2.5 mg/dLに達すると、溶けきれないビリルビンが組織に拡散し、皮膚や白眼が黄色く染まる。

間接型か直接型か

増加するものポイント
間接（非抱合型）が増加肝臓で処理（抱合）される前の段階の問題（例：溶血性貧血）水に溶けないため尿中には排泄されない（無胆汁尿性黄疸）。脳に移行して神経障害（核黄疸）を起こす危険
直接（抱合型）が増加肝臓で処理した後の排泄ルートの問題（例：胆道の閉塞）水に溶けるため尿中へ排泄され、尿が濃い褐色になる（胆汁尿性黄疸）
