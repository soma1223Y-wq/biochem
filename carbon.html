1アミノ酸の炭素骨格の行き先

アミノ基を除いた炭素骨格は、7つの代謝中間体に集約される。

  • 糖原性アミノ酸：ピルビン酸、α-ケトグルタル酸、スクシニルCoA、フマル酸、オキサロ酢酸になる → クエン酸回路で酸化（ATP）あるいはグルコース合成。
  • ケト原性アミノ酸：アセチルCoA、アセトアセチルCoAになる → ケトン体や脂肪酸の合成（グルコースには変換できない）。
  • ロイシン・リシンは純粋なケト原性。
  • 例：アスパラギン →（アスパラギナーゼ）→ アスパラギン酸 →（アミノ基転移）→ オキサロ酢酸。
覚える

ノートの指示：「これを覚えましょう！」＝ 糖原性／ケト原性の振り分けと、7つの中間体への集約。

例題 1-1

純粋なケト原性アミノ酸の組合せはどれか。
A ロイシン・リシン　B アラニン・セリン　C アスパラギン・アスパラギン酸　D フェニルアラニン・チロシン　E バリン・イソロイシン

答えを見る

A。

2アミノ酸代謝の先天性代謝異常

疾患欠損酵素症状・ポイント
高アルギニン血症アルギナーゼ（尿素回路）尿素回路の一つとして重要。2〜4歳頃まで症状が目立たない
フェニルケトン尿症（PKU）フェニルアラニンヒドロキシラーゼ重度の精神遅滞。Phe過剰 → フェニルピルビン酸・フェニル乳酸・フェニル酢酸が増加。治療はフェニルアラニン制限食。Tyrが本来作れず必須となる
メープルシロップ尿症（MSUD）分枝α-ケト酸デヒドロゲナーゼ複合体尿がメープルシロップ臭、重度の神経障害。分岐鎖アミノ酸（Leu, Val, Ile）の共通の最初の3反応（アミノ基転移、脱炭酸、脱水素）。遺伝的多様性あり
アルカプトン尿症ホモゲンチジン酸1,2-ジオキシゲナーゼ黒色尿、オクロノーシス（関節への色素沈着）。チロシン異化経路
ホモシスチン尿症シスタチオニンβ-シンターゼ骨格異常、精神遅滞、心血管疾患リスク上昇。ホモシステインの蓄積が原因

先天性代謝異常を防ぐには

  • 早期発見が最善。方法として新生児マススクリーニング（タンデム質量分析法）。
  • 生後数日の新生児の血液（濾紙血）から、アミノ酸・アシルカルニチンを一度に測定できる。症状が出る前に診断し、食事療法などを始められる。
ひっかけ

PKUは「フェニルアラニン→チロシン」の酵素欠損。メープルシロップ尿症は「分岐鎖α-ケト酸」の脱水素酵素欠損。ホモシスチン尿症はシスタチオニンβ-シンターゼ。名称と酵素の組合せで出題される。

例題 2-1

尿が黒色になり、関節に色素沈着を来す先天性代謝異常症はどれか。
A PKU　B MSUD　C アルカプトン尿症　D ホモシスチン尿症　E 高アルギニン血症

答えを見る

C。

3アミノ酸の特殊生成物への変換

アミノ酸はタンパク質の材料だけでなく、生命維持に必要な多様な分子の前駆体になる。

前駆体 → 生成物役割
A エネルギー代謝・細胞機能メチオニン → SAM主要なメチル基の運び屋（ATPからアデノシル基を受ける）
Arg＋Gly＋Met(SAM) → クレアチン筋肉のエネルギー貯蔵。クレアチニンは腎機能の指標
アルギニン → NONO合成酵素。血管平滑筋を弛緩させる
B 神経伝達物質・ホルモンチロシン → カテコールアミンドーパミン・ノルアドレナリン・アドレナリン。甲状腺ホルモン
トリプトファン → セロトニン、メラトニンセロトニン（気分の安定）、メラトニン（睡眠）
ヒスチジン → ヒスタミンアレルギー・胃酸分泌・覚醒
C 非α-アミノ酸などグルタミン酸 → GABA脳の主要な抑制性神経伝達物質（ブレーキ）
β-アラニン補酵素A（パントテン酸）の構成、カルノシン（筋肉の緩衝成分）
例題 3-1

アルギニンから合成される血管拡張性のシグナル分子はどれか。
A ヒスタミン　B GABA　C NO　D セロトニン　E クレアチン

答えを見る

C。
