1解糖の概要：酸素の有無で行き先が変わる

グルコースを解糖するとピルビン酸ができる。

条件ピルビン酸の行き先
嫌気的条件（O₂が少ない）①ピルビン酸 → 乳酸、②NADH → NAD⁺（NAD⁺が再生され解糖が続く）
好気的条件（O₂がある）ピルビン酸 → アセチルCoA（クエン酸回路で使用される）
  • 骨格筋は嫌気的条件下で蓄積したグリコーゲンを消費し、ピルビン酸から乳酸が産生される。NADHの再酸化によりNAD⁺が再利用される。
  • 赤血球はミトコンドリアをもたないため、好気的でも乳酸は産生される（ミトコンドリアで酸化できない）。

解糖とピルビン酸酸化（ハーパー17章）

解糖ピルビン酸酸化
場所細胞質ミトコンドリアのマトリックス
酸素好気・嫌気どちらでも進む好気的条件でのみ進む（クエン酸回路・電子伝達系も同様）
反応グルコース（C6）→ピルビン酸（C3）×2ピルビン酸 → アセチルCoA＋CO₂＋NADH
正味2 ATP＋2 NADHNADH×2（グルコース1分子あたり）
  • 赤血球はミトコンドリアをもたない → ピルビン酸酸化が起こらない → エネルギー源は解糖で得られる2 ATPと2 NADHのみ。
  • 解糖・ピルビン酸酸化では NAD⁺→NADH が起こる。NADHは電子伝達系のATP産生に用いられる＝NADHは実質エネルギー源。

3不可逆反応・律速段階と、その逆反応の酵素

  • 解糖は細胞質で、好気的・嫌気的条件どちらでも進む（O₂に依存しない）。
  • 解糖の不可逆反応は3つ：(i) ヘキソキナーゼ（グルコース→G6P）、(ii) ホスホフルクトキナーゼ-1（F6P→F1,6BP）、(iii) ピルビン酸キナーゼ（PEP→ピルビン酸）。
  • 解糖の律速（反応速度を決める）はホスホフルクトキナーゼ-1（PFK-1）。ATPで阻害、G6Pでヘキソキナーゼが阻害される。
解糖（順方向）逆反応（糖新生）
①ヘキソキナーゼ／グルコキナーゼ（ATP→ADP）グルコース-6-ホスファターゼ（加水分解でH₃PO₄遊離）
③ホスホフルクトキナーゼ-1（ATP→ADP）フルクトース-1,6-ビスホスファターゼ
⑩ピルビン酸キナーゼ（ADP→ATP）逆反応の酵素はない → ピルビン酸カルボキシラーゼ＋PEPカルボキシキナーゼで迂回
  • リン酸基が付加／加水分解されるとき、ATP⇄ADP、あるいはH₃PO₄とともにリン酸基の加水分解が起こる。
  • ⑥のGAPDHではHの転移が起こるため NAD⁺⇄NADH。H₃PO₄によってリン酸基が付加／加水分解される。
  • ⑦のPGKはATP⇄ADP（ここだけ可逆）。

4覚え方：構造変化と酵素名のルール

（ノートの個人的な覚え方。スライドの構造式は誤りがあるので参考にしない、との注意あり。）

① 中間体の間での変化と、どこが不可逆かを覚える

  • グルコース→G6P：6位がリン酸化（不可逆）。
  • G6P→F6P：C1がアルデヒド（CHO）→C2がケトンへ。アルドースがケトースに（可逆）。
  • F6P→F1,6BP：1位がリン酸化（不可逆・律速）。
  • F1,6BP→DHAP＋GAP：C3とC4の間で切断（C6→C3×2）。DHAPはGAPに異性化。
  • GAP→1,3-BPG：アルデヒドが酸化されてカルボン酸（リン酸）に。1位に高エネルギーのリン酸。
  • 1,3-BPG→3PG：1位のリン酸をADPに渡す（ATP産生）。
  • 3PG→2PG：リン酸基が3位から2位へ（ムターゼ）。
  • 2PG→PEP：脱水（エノラーゼ）。
  • PEP→ピルビン酸：エノール型→ケト型。不可逆。

② 酵素名の決まり方

大体の名前 ＝（基質名の略）＋（特定の作用と対応した酵素の名称）。

酵素の名称作用
キナーゼATPなど高エネルギーリン酸基からリン酸基を転移
ホスファターゼリン酸エステルを加水分解
イソメラーゼ構造異性化
デヒドロゲナーゼHを脱離し別の物質へ転移（脱水素反応）
ムターゼ官能基に特化した構造異性化（イソメラーゼの一部）

※アルドラーゼ・エノラーゼは固有名で例外。可逆反応の場合、逆反応から名付けられている酵素もある（例：PEP→ピルビン酸はピルビン酸キナーゼ）。

5ATP産生量（好気・嫌気）

NADH＝2.5 ATP、FADH₂＝1.5 ATPに相当（覚える！）。エネルギー産生は、どの過程で生じるかを考えず量だけで考えると誤る。

条件計算ATP
解糖（好気）2 NADH＋2 ATP＝2×2.5＋27
ピルビン酸酸化＋クエン酸回路8 NADH＋2 FADH₂＋2 ATP(GTP)＝8×2.5＋2×1.5＋225
合計7＋2532 ATP
解糖（嫌気）4−22

嫌気的条件では、NADH・FADH₂が電子伝達系で働かないため、ATPは産生できない（2 ATPのみ）。同量のATPを得るにはより多くのグルコースを代謝しなければならない。

例題 5-1

グルコース1分子を好気的に完全酸化したときのATP産生量に最も近いのはどれか。
A 2　B 7　C 25　D 32　E 38

答えを見る

D。

6悪性リンパ腫・FDG-PET・ワールブルグ効果

FDG-PET

  • 悪性リンパ腫はグルコースを取り込み、解糖する。PET（陽電子放出断層撮影）画像を診断に用いる。
  • FDG：グルコースの2位が−OH→−¹⁸F（放射性に変化したもの）。FDGは解糖の過程でヘキソキナーゼによりリン酸化されるが、それ以降は代謝されず蓄積する → PETで写る。

好気的解糖（ワールブルグ効果）

通常は好気的条件下で、グルコース→解糖→ピルビン酸→クエン酸回路・酸化的リン酸化→多くのATP（32ATP）。しかしがん細胞では好気的でも、グルコース→解糖→ピルビン酸→嫌気的解糖→乳酸＋少しのATP（2ATP）。

がん細胞が好気的解糖をするメリット：

  • ① ATPをすばやく産生。
  • ② 解糖の中間生成物から脂質・アミノ酸・核酸を合成できる → 細胞の成長促進。
  • ③ 乳酸が増加 → 酸性化 → 免疫による排除が弱まる → がん細胞の浸潤・成長を促進。

赤血球の迂回経路（ラパポート・リューベリング経路）

  • 通常：1,3-BPG →（PGK、ATP産生）→ 3PG。
  • 赤血球特有：1,3-BPG →（ビスホスホグリセリン酸ムターゼ）→ 2,3-BPG →（2,3-BPGホスファターゼ）→ 3PG。
  • デメリット：本来の経路で発生するATP産生が無くなる。メリット：2,3-BPGはヘモグロビンと結合しO₂親和性を低下 → ヘモグロビンから組織へのO₂の運搬量が増加。
例題 6-1

ワールブルグ効果について正しいのはどれか。
A 嫌気的条件でのみ解糖が亢進する　B 好気的条件でも解糖で乳酸を産生する　C ATP産生効率が高い　D ミトコンドリアが増加する　E 乳酸産生が低下する

答えを見る

B。

7ピルビン酸デヒドロゲナーゼ（PDH）とビタミンB₁

解糖で得られるピルビン酸はPDHにより ピルビン酸＋CoA＋NAD⁺ → アセチルCoA（C2）＋CO₂＋NADH（不可逆）。補酵素A（CoA）にアセチル化したC₂＝アセチルCoA。

アセチルCoAはエネルギー産生（クエン酸回路）、エネルギー過剰時の脂肪酸合成に用いられる。

  • PDHの活性化にはビタミンB₁（チアミン）由来のチアミンピロリン酸（TPP）が必要。
ビタミンB₁欠乏

ビタミンB₁不足 → TPP不足 → PDH不活性 → ピルビン酸が増加 → 乳酸増加 → 乳酸アシドーシス（体内のpH低下）、ATP産生低下 → 病気：脚気、ウェルニッケ脳症、コルサコフ症候群。

例題 7-1

PDHの活性化に必要な補酵素でビタミンB₁由来のものはどれか。
A FAD　B NAD⁺　C TPP　D リポ酸　E CoA

答えを見る

C。

8クエン酸回路の概要と医学的重要性

  • 糖質・脂質・タンパク質の酸化のための最終的な共通回路。
  • アセチルCoAのアセチル部分（C2）がオキサロ酢酸（C4）と反応してクエン酸（C6、トリカルボン酸）を生成してスタート。
  • 途中で2分子のCO₂が放出され、オキサロ酢酸が再生される（回路維持にはオキサロ酢酸の再生が重要）。
  • 酵素はミトコンドリアのマトリックスに局在する。
  • アセチルCoAの酸化の間に補酵素は還元され、共役して続く呼吸鎖でATPが産生される（酸化的リン酸化）。この過程は好気的で、酸化剤として酸素を必要とする。

医学的重要性

  • 高アンモニア血症：血中アンモニアが上昇 → 肝細胞での尿素回路でアンモニアを処理 → クエン酸回路の中間生成物（α-ケトグルタル酸など）を過剰に利用 → 回路が回らずATP合成低下。
  • クエン酸回路の酵素が欠損すると、特に中枢神経でATP合成が低下し、神経障害を起こす。
例題 8-1

クエン酸回路について正しいのはどれか。
A 酵素は細胞質に局在する　B アセチルCoAとオキサロ酢酸からクエン酸が生じる　C 回路1周で4分子のCO₂が放出される　D 嫌気的条件で進む　E 糖質のみの酸化経路である

答えを見る

B。1周で2分子のCO₂、好気的、3大栄養素に共通。

9呼吸の目的と補酵素の再生

呼吸の目的はATPを産生してエネルギーを取り出すこと。そのために電子（e⁻）を利用する。

  • 基質を酸化（e⁻を奪い取る）してe⁻を得る。
  • ここで使うのがNAD⁺・FAD（酸化型補酵素）。基質を酸化し、自身はNADH・FADH₂（還元型補酵素）となり、「e⁻の運び屋」になる。
  • 代謝を常に行うには酸化型補酵素を再生させる必要がある → O₂が酸化剤としてHを受け取り（→H₂O）、ここで放出されるe⁻のエネルギーとH⁺の濃度勾配を利用してATPを合成（酸化的リン酸化）。
換算ATP
NADH 1分子2.5 ATP
FADH₂ 1分子1.5 ATP
GTP 1分子1 ATP

11各反応の酵素名と特徴

酵素特徴
1クエン酸シンターゼアセチルCoA＋OAA→クエン酸。不可逆。チオエステル結合が加水分解され、CoA-SHが遊離する。
2アコニターゼクエン酸をcis-アコニット酸経由でイソクエン酸に異性化。鉄-硫黄タンパク質。脱水→水和の2段階。立体特異的で、イソクエン酸が大量にあるとアコニターゼを阻害（クエン酸が蓄積）＝負のフィードバック。
3イソクエン酸デヒドロゲナーゼ脱炭酸（CO₂放出）し、NADH産生。律速反応・不可逆反応。NAD⁺依存性のものがミトコンドリアに存在。
4α-ケトグルタル酸DH複合体CO₂放出、NADH産生、不可逆。→スクシニルCoA。
5コハク酸チオキナーゼ（スクシニルCoAシンテターゼ）スクシニルCoA→コハク酸。基質レベルのリン酸化でGTPを産生（GTP＋ADP⇄GDP＋ATP）。回路で唯一の基質レベルのリン酸化。
6コハク酸デヒドロゲナーゼFADと鉄-硫黄タンパク質を含む。ミトコンドリア内膜に埋め込まれている。FADH₂産生。コハク酸→フマル酸。
7フマラーゼフマル酸に水を付加してリンゴ酸に。
8リンゴ酸デヒドロゲナーゼリンゴ酸→OAA。NADH産生。OAAは次のサイクルへ、または糖新生の基質、アミノ基転移でアスパラギン酸に。

1回転：NADH×3＋FADH₂×1＋GTP×1＝10 ATP。

12代謝とエピゲノム制御：IDH変異とがん

IDH変異 → α-ケトグルタル酸の代わりに 2-HG（D-2-ヒドロキシグルタル酸）が蓄積 → α-ケトグルタル酸依存性酵素を競合的に阻害 → 遺伝子が正常に脱メチル化（活性化）されない → がん化

  • IDH遺伝子変異をもつ腫瘍：神経膠腫（二次性膠芽腫で約70〜80%、びまん性神経膠腫）、急性骨髄性白血病（AML）の約15〜20%、軟骨肉腫、肝内胆管癌。
  • 代謝物がエピゲノム（DNA・ヒストンのメチル化）を介して遺伝子発現を制御し、がん化に関わる代表例。
